# Scopewatch

**Operator tendency and sniper profiler for VALORANT coaches.** Built for the Cloud9 x JetBrains *Sky's The Limit* 2026 hackathon (Category 1: VALORANT Tactical Scouting).

Pick an opponent, a map and a side. Scopewatch answers the questions a coach asks about the other team's Operator, and shows the rounds behind every answer:

- **How often they have it**, by economy, and how often they win with it vs without.
- **Who carries it**, on which agents, and how often it changes hands.
- **When it fires**: kills by time since the buy phase ended, before and after the plant.
- **Opening duels**: how often the rifle takes the first kill, or its holder dies first.
- **Where they fight from**: shooter→victim lines on a map drawn from pro positional data, and how far forward they play compared with every team on that map.

Every number carries its sample (*k* of *n*), a likely range, and a **Show the rounds** link to the supporting and contrary rounds, down to the kill timeline. Nothing is generated by a chatbot.

## How it works

```
GRID feeds + ability supplement (.jsonl.zst, read in place, streamed)
  └─► engine/ingest    series reducer: round/phase state machine, undo stack for GRID reversals,
                       cast quality policy, per-series reconciliation counts, source manifest
  └─► cache/v2/raw     canonical parquet tables (git-ignored)
  └─► engine/store     DuckDB: rounds, team rounds, engagements, casts, spawns …
  └─► engine/metrics   versioned metric registry → n/N, unknowns, Wilson ranges, evidence round keys
  └─► api/             FastAPI, typed envelopes with coverage, warnings, dataset revision, filter hash
  └─► web/             React + Vite UI
```

Map outlines are drawn from where players have stood across about 2,000 pro maps, so no game art is used and the map always lines up with the data.

## Running it

The licensed GRID data is **not** in this repo. Clone it next to this project:

```
your-folder/
├── stl-hackathon-2026-grid-starter/   # GRID data (never committed)
└── scopewatch/                        # this repo
```

```bash
git clone --filter=blob:none --sparse https://github.com/cloud9esports/stl-hackathon-2026-grid-starter.git
cd stl-hackathon-2026-grid-starter && git sparse-checkout set val val-ability-supplements meta && cd ..
cd scopewatch
pip install -r requirements.txt
python -m engine.ingest.run       # ~20 min on 10 workers; re-runs skip unchanged series
python -m engine.store            # analytical DuckDB
python -m engine.maps             # map outlines
uvicorn api.server:app --port 8000
cd web && npm install && npm run dev   # http://localhost:5173
```

Set `STL_DATA_DIR` if the data lives somewhere else. Run the tests with `python -m pytest tests`; they use synthetic feeds only.
